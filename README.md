# Velocity Chess Academy — Premium Website

A clean, premium, India-first redesign built using only HTML, CSS and JavaScript.

## Files

- `index.html` — complete website structure and content
- `styles.css` — responsive premium design system
- `script.js` — mobile menu, scroll reveal, active navigation and WhatsApp enquiry
- `assets/` — supplied academy logo and photography

## Main design direction

- Brand-led yellow used as a strong accent rather than a dull full-page background.
- Warm ivory/white canvas with near-black typography for a premium editorial feel.
- Real supplied images used throughout the homepage.
- IM Krishna Teja is the visual and credibility anchor.
- Mobile-first responsive navigation.
- Strong conversion path: Free Trial → enquiry form → WhatsApp.
- No framework or backend required.
